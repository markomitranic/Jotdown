Type `/whiteboard` on an empty line and choose **Whiteboard**. Click **Edit
whiteboard** to open Excalidraw.

Use Excalidraw's drawing, text and image tools. You can also import an existing
`.excalidraw` file from its menu. Click **Apply to page** to put the drawing into
your browser draft, then use the page's **Save changes** button to save it.
Changes inside the canvas are not part of the page draft until you apply them.
Cancel asks before discarding changes.

## What gets saved

In a GitHub project, Save makes one commit on the project's branch, made with
your GitHub token and credited to whoever `git config --global` names. In a folder project it writes the same
files to disk and commits nothing. Either way you get the page, an editable
`.excalidraw` JSON file and a PNG preview. Images
inside the drawing are embedded as data URLs in the JSON. The preview displays
without loading the drawing editor, and **Download drawing** returns the
editable file.

The page refers to the pair with a component:

```mdx
<Whiteboard src="/whiteboards/<hash>.excalidraw" preview="/whiteboards/<hash>.png" />
```

The files live in the project's `docs/_uploads/whiteboards/` folder and are served at
`/whiteboards/<file>`. Their names come from their contents, so editing a copied
drawing creates a new pair instead of overwriting another page's drawing. A
board deleted before its first save creates no files.

Previous pairs stay in the repository after a drawing changes. To clear them
out, run the prune script from a checkout of Jotdown against a clone of the
project. `bun run prune-uploads ../notes` lists the unreferenced images,
files and whiteboards, and `bun run prune-uploads ../notes --delete` deletes
them and stages the deletions for you to review, commit and push. Leave out the
folder and it checks the framework's own repository.

## Images and editing together

A drawing and its preview can total up to 3 MB. A page save can carry up to 4 MB
including its other changes. If a drawing is too large, reduce the images before
applying it. Export from Excalidraw's menu if you need to keep a larger drawing.

The page's source-version check prevents a stale save from replacing newer
content, so a drawing applied to a page that changed elsewhere asks for a
reload rather than overwriting it.
