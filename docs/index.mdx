Jotdown keeps your notes, docs and personal site as **markdown in git**, and
gives you a studio that edits those pages in place, in the site's own look.
There is no database and no account to make: the files are the data. The same
folder is read three ways:

<Steps>
  <Step>
    **Studio**, for you. It runs on your own machine and edits a folder on disk or a GitHub repository, where a save is a commit. [Set up a project](./studio/setting-up-a-project.mdx).
  </Step>

  <Step>
    **Site**, for your readers. A read-only website built from the same pages, deployed wherever you like. [Publish it](./publication/publishing.mdx).
  </Step>

  <Step>
    **Context Warehouse**, for your agents. The pages are plain files in the repository, so an agent reads them before it touches the code, and keeps them current. [Connect your agents](./context-warehouse/connecting-agents.mdx).
  </Step>
</Steps>


## Set up your docs

<Steps>
  <Step>
    ### Install the app

    Download the DMG from the [latest release](https://github.com/markomitranic/Jotdown/releases/latest), drag Jotdown into Applications and open it, with one **Open Anyway** in System Settings the first time. If your pages live on GitHub, click **Sign in to GitHub** in the top right. [Installing the app](./studio/local-studio.mdx) has every step.
  </Step>

  <Step>
    ### Set up a new project

    In the project picker, choose **Add a project**, then **Set up a new project**. Pick a repository or a folder and answer the questions. The last one lists every file it will write: `.jotdown/config.json`, the first pages, the docs skills for your agents and a note in `AGENTS.md`. A repository gets them as one commit on its default branch, a folder gets them on disk, and the project opens straight away. [Setting up a project](./studio/setting-up-a-project.mdx) has every step.
  </Step>

  <Step>
    ### Ask your agent for a real page

    Paste [the first-page prompt](./studio/local-studio.mdx#ask-your-agent-for-a-first-page) into Claude Code, Codex or Cursor in the repository: the agent finds something hard to explain in your code, offers three candidates and writes a page with a figure. Open it in the studio and [review it](./context-warehouse/reviewing-agent-pages.mdx): click a sentence and fix it.
  </Step>
</Steps>
