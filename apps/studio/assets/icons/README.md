# Studio icons

Full-resolution originals, 1254×1254, and placeholders until Jotdown has an
icon of its own. Nothing serves these directly: `public/icon.png`,
`public/favicon.png` and `public/apple-icon.png` were cut from
`docs-production.png`, and the app icon is made from it too.

| File | What it is |
| --- | --- |
| `docs-concentrating.png` | The baseline drawing every other icon is made from. |
| `docs-production.png` | The studio's icon. |
| `docs-nightly.png` | A night-sky variant, unused. |

Publications are not branded with these. Each one wears the project's
own `favicon` from `.jotdown/config.json`.
